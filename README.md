## MDCx-diy 是什么

MDCx-diy 是一个桌面工具，自动从 37 个网站抓取视频文件的元数据（标题、演员、封面、简介等），生成标准的 .nfo 文件和整理好的文件夹，给 Emby、Jellyfin、Kodi 这类媒体服务器直接用。

一句话：把一堆乱七八糟的视频文件，变成媒体服务器能认的整齐资料库。
